# Комплексный анализ операционных показателей розничной сети

### Контекст кейса
* **Объект:** Розничная сеть (продуктовый ритейл 24/7, Москва).
* **Специфика:** Гибридная система оплаты (обычные кассы и КСО), накопительная программа лояльности.
* **Инструменты:** Excel (сводные таблицы, сложные формулы), Google Sheets (Query, Dashboarding), PowerPoint.

---

### Основные этапы работы

| Задача | Решение | Результат (Insight) |
| :--- | :--- | :--- |
| **Анализ динамики транзакций** | Построение сводных таблиц и визуализация трендов по дням. | Выявлен эффект **каннибализации**: открытие новой точки привело к оттоку части трафика из существующего магазина в том же районе. |
| **Оценка нагрузки на IT-инфраструктуру** | Анализ распределения транзакций по серверам и расчет среднего времени обработки платежа.| Обнаружен резкий скачок нагрузки на конкретных узлах. Предложена схема балансировки, снижающая риск задержек при оплате. |
| **Анализ влияния тех. сбоев** | Фильтрация данных на основе логов разработки и расчет «чистого» времени платежа. | Показано, что рост среднего времени транзакции коррелирует с периодами тех. сбоев, что позволило отделить системные ошибки от человеческого фактора. |
| **Оценка эффективности промо-акции** | Сравнительный анализ (LFL) показателей до и во время акции на 7-й день. | Отцифрован аплифт выручки и изменение среднего чека в период проведения маркетинговой активности. |
| **Оптимизация программы лояльности** | Анализ структуры скидок и их влияния на итоговую выручку. | Выявлены зоны потери выручки. Подготовлены рекомендации по корректировке порогов скидок для повышения доходности. |
| **Автоматизация операционной отчетности** | Создание интерактивного дашборда в Google Sheets для анализа исторических данных. | Автоматизирована сборка отчетов по выручке и чекам, что позволяет быстро находить аномалии в прошлых периодах. |
| **Оптимизация затрат на сервера** | Рефакторинг и исправление логики в отчете-калькуляторе транзакционных издержек. | Обеспечена высокая точность расчета фактических затрат на каждый сервер с учетом экономии на масштабе. |
