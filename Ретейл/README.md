### Контекст кейса
Данные - транзакции розничной сети круглосуточных продуктовых магазинов.  
Расположение - районы города Москвы.  
Способ оплаты - обычная касса или касса самообслуживания.  
Действует программа лояльности - скидка в форме определенного процента от суммы покупки.  
Размер скидки - чем больше покупок было раньше, тем выше.

### Задачи → Решения → Результаты
- Проанализировать активность транзакций в первые 4 дня
1) Построены сводная таблица и диаграммы кол-ва транзакций в динамике по дням 
2) Зафиксирован рост общего числа транзакций
3) Выявлен эффект "Каннибализации": часть клиентов перешла с одной точки на другую 
  
- Оценить нагрузку на наши сервера и эффективность касс самообслуживания
1) Предложена сбалансированная схема распределения нагрузки по серверам и
2) Обнаружена проблема распределения нагрузки по серверам и рост среднего времени платежа

- Выяснить влияние тех. сбоев на работу торговых точек

  
- Отцифровать эффект акции, проведенной на 7 день

  
- Пересмотреть программу лояльности с учетом потерь выручки

  
- Собрать в Google Sheets дашборд для операционной аналитики

  
- Исправить и оптимизировать отчет-калькулятор по затратам на сервера

  
- Подготовить презентацию результатов работы
