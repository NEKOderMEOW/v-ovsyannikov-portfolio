# Комплексный анализ операционных показателей розничной сети

### Контекст кейса
* **Объект:** Розничная сеть (продуктовый ритейл 24/7, Москва).
* **Специфика:** Гибридная система оплаты (обычные кассы и КСО), накопительная программа лояльности.
* **Инструменты:** Excel (сводные таблицы, сложные формулы), Google Sheets (Query, Dashboarding), PowerPoint.

---

### Основные этапы работы

1. **Анализ динамики транзакций**
    * **Решение:** Построение сводных таблиц и визуализация трендов по дням.
    * **Результат:** Выявлен эффект **каннибализации**: открытие новой точки привело к оттоку части трафика из существующего магазина в том же районе.

2. **Оценка нагрузки на серверную инфраструктуру**
    * **Решение:** Анализ распределения транзакций по серверам и расчет среднего времени обработки платежа.
    * **Результат:** Обнаружен резкий скачок нагрузки на конкретных узлах. Предложена схема балансировки, снижающая риск задержек при оплате.

3. **Анализ влияния тех. сбоев на время платежа**
    * **Решение:** Фильтрация данных на основе логов разработки и расчет "чистого" времени платежа.
    * **Результат:** Показано, что рост среднего времени транзакции коррелирует с периодами тех. сбоев; это позволило отделить системные ошибки от влияния человеческого фактора.

4. **Оценка эффективности промо-акции**
    * **Решение:** Сравнительный анализ показателей (LFL) до и во время акции на 7-й день.
    * **Результат:** Отцифрован **аплифт (uplift)** выручки и изменение среднего чека в период проведения маркетинговой активности.

5. **Оптимизация программы лояльности**
    * **Решение:** Анализ структуры скидок и их влияния на итоговую выручку.
    * **Результат:** Выявлены зоны потери выручки. Подготовлены рекомендации по корректировке порогов скидок для повышения доходности.

6. **Автоматизация операционной отчетности**
    * **Решение:** Создание интерактивного дашборда в Google Sheets для анализа исторических данных.
    * **Результат:** Автоматизирована сборка отчетов по транзакциям, что позволяет оперативно находить аномалии в прошлых периодах.

7. **Рефакторинг расчета затрат на сервера**
    * **Решение:** Исправление логики в отчете-калькуляторе транзакционных издержек.
    * **Результат:** Обеспечена высокая точность расчета фактических затрат на каждый сервер с учетом **экономии на масштабе**.
